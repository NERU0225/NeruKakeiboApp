# 家計簿

レシート単位で記録し、明細1行ごとにカテゴリを付けられる家計簿アプリ。
サーバーは使わず、データは自分の端末（ブラウザ）の中だけに保存されます。

## 公開のしかた（GitHub Pages）

パソコンからのほうが楽ですが、iPhoneのSafariでもできます。

1. **GitHubに登録** — https://github.com/signup （無料）
2. **リポジトリを作る**
   - 右上の「＋」→ **New repository**
   - Repository name: `kakeibo`（好きな名前でOK）
   - **Public** を選ぶ（Privateだと無料ではPagesが使えません）
   - **Create repository**
3. **ファイルをアップロード**
   - **uploading an existing file** のリンクをタップ
   - この6つを全部選んでアップロード
     - `index.html`
     - `manifest.json`
     - `sw.js`
     - `icon-180.png`
     - `icon-192.png`
     - `icon-512.png`
   - 下の **Commit changes** を押す
4. **Pagesを有効にする**
   - **Settings** タブ → 左メニューの **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / フォルダ: **/ (root)** → **Save**
5. **1〜2分待つ**と、Pagesの画面にURLが出ます

   ```
   https://<ユーザー名>.github.io/kakeibo/
   ```

## iPhoneのホーム画面に置く

1. Safariで上のURLを開く
2. 下の **共有ボタン**（□に↑）をタップ
3. **ホーム画面に追加** → 追加

アドレスバーのないアプリとして開き、機内モードでも起動します。

> **Chromeではなく必ずSafariで**開いてください。iPhoneではSafariから追加したものだけがきちんと動きます。

## 更新のしかた

`index.html` と `sw.js` を差し替えてアップロードし直します（同名で上書き → Commit）。
通信がある状態で開くと自動で新しい版に切り替わり、「vX に更新しました」と出ます。

記録したデータはブラウザ側にあるので、更新しても消えません。

> 差し替える2つのファイルは、**バージョン番号が一致している必要があります**
> （`index.html` の `APP_VERSION` と `sw.js` の `CACHE`）。
> 番号を上げ忘れると新しい版が反映されません。

## データについて

- 保存先はブラウザの `localStorage`。**年ごとに分けて**保存しています（`kakeibo:y:2026` など）
- 起動時に読むのは今年のぶんだけ。他の年は、その年に移動した時に読みます
- 設定タブから、年を選んで `kakeibo-年.json` の形で書き出し／読み込みができます
- 読み込みは複数ファイルをまとめて選べます
- 最後の書き出しから14日たつと、画面上部に案内が出ます

### 注意

Safariは、しばらく開かないサイトの保存データを消すことがあります。
ホーム画面に追加して普段から使っていれば基本的に大丈夫ですが、**月に一度は書き出して**iCloudなどに置いておくと安心です。

- 書き出し：設定タブ →「書き出す」→ 共有シート →「ファイルに保存」
- 読み込み：設定タブ →「読み込む」→ ファイルを選ぶ

## 使い方

### 入力
右下の **＋** で入力します。1レシート＝1記録です。

```
店名   セブンイレブン
支払い 現金
明細   海苔弁当  ¥550  食費
       金ピース  ¥600  タバコ
合計   ¥1,150
```

- 明細は行ごとに金額とカテゴリを付けられます。集計もグラフも明細単位です
- 店名・品名は過去の入力から候補が出ます。品名の候補を選ぶと金額やカテゴリも入ります
- 値引きや返金は**金額をマイナス**で入れます
- 明細ごとに**税込／税抜**を選べます。税抜は税率ごとにまとめて計算します
- 「区間」を開くと、乗った場所・降りた場所を記録できます（高速道路や電車）
- よく買う組み合わせは「テンプレとして保存」で登録し、次回から「☆ テンプレから入力」で呼び出せます

### タブ
| タブ | できること |
|---|---|
| ホーム | 今月の収支、予算の残り、カード請求、残高、最近の入出金 |
| カレンダー | 日別の収支。日付をタップでその日の一覧。同じ日の並び順は ≡ で入れ替え |
| 集計 | グラフ（月／年／期間で切替）と履歴（店名・品名・メモの横断検索）。内訳をタップするとその明細の一覧が見られます |
| 経費 | 立替の残額と、申請済・精算済への一括変更 |
| 予算 | 月の総額とカテゴリ別の予算 |
| 設定 | カテゴリ／お金／カード／定型／固定費／税率／バックアップ |

### お金とカード
- **お金の置き場所**（現金・口座・電子マネー）を設定タブの「お金」に登録します。残高が自動で計算されます
- **カード**は「カード」に登録し、締め日・引落し日・引落し口座を設定します
- 口座間の振替、ATMでの引き出し、電子マネーへのチャージは、入力画面の「**移動先**」を選びます。これらは支出に計上されません
- 電子マネーで払った分は集計に入りません（チャージ時に計上済みのため）

### 固定費
家賃・保険・サブスクなどを設定タブの「固定費」に登録すると、支払日が来たときに自動で記録されます。
金額と支払い方法は「この日から◯◯」という形で複数持てるので、値上がりや支払い方法の変更も先に登録できます。

### その他
- ヘッダー左のバージョン番号をタップすると更新履歴が見られます
- ヘッダー右の「金額を隠す」で、残高とカード請求を伏せられます
- シートは上部のつまみを下にスワイプしても閉じられます
